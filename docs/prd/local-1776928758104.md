# PRD: Delivvr UI/Design Overhaul & Profile Page Enhancement

- **Ticket ID:** local-1776928758104
- **Date:** 2026-04-23
- **Author:** Ticket Writer Agent
- **Status:** Draft

---

## Problem Statement

The current Delivvr web application suffers from a generic, unattractive visual design that does not reflect the Delivvr brand identity. Several CSS classes referenced in the EJS templates are undefined, causing broken layouts on key pages. The application still carries the placeholder name "Express Auth App" throughout titles, navbars, and footers rather than the Delivvr brand. The color palette is a plain blue scheme with no relation to delivery or logistics aesthetics. Additionally, the profile page lacks visual structure — it shows raw data without an avatar, icon-labeled rows, or intuitive navigation back to the dashboard. These issues collectively result in a poor user experience that undermines trust and engagement. A full design overhaul is required to establish a cohesive, branded, and visually polished interface across all six views.

---

## Acceptance Criteria

- All occurrences of "Express Auth App" are replaced with "Delivvr" across every EJS view, browser tab title, navbar brand, and footer text.
- The CSS custom properties in `public/css/style.css` define `--primary` as `#FF6B00` (bold orange) and `--accent` as `#00BFA5` (teal) for both the light and dark theme blocks.
- The following previously undefined CSS classes are fully defined with appropriate styles in `style.css`: `.md-profile-item`, `.md-card-body`, `.md-button-group`, `.md-profile-error`, `.md-tech-grid`, `.md-tech-item`, `.md-chip`, `.md-section-cta`.
- The navbar brand in `views/layout.ejs` displays a `bi-truck` Bootstrap Icon prefix followed by the word "Delivvr"; the footer reads "Delivvr" and not the old placeholder text.
- The home page (`views/index.ejs`) features delivery-focused hero copy and includes Bootstrap Icons `bi-truck`, `bi-box-seam`, and `bi-geo-alt` in the feature/value-proposition section.
- The login page (`views/login.ejs`) displays a Delivvr-branded logo or wordmark in the card header, uses the new `#FF6B00` primary color for the submit button, and all form inputs have visible `:focus` states consistent with the new palette.
- The signup page (`views/signup.ejs`) mirrors the login page improvements: branded card header, updated color palette, and modern input field styling.
- The dashboard page (`views/dashboard.ejs`) shows a delivery-themed welcome banner that includes the authenticated user's name, wraps statistics in visually distinct `.md-card` cards, uses delivery-relevant Bootstrap Icons, and displays status indicators as `.md-chip` badge elements.
- The profile page (`views/profile.ejs`) renders a circular avatar displaying the user's initials styled with the `#FF6B00` primary-color background, presents each profile field as an `.md-profile-item` row containing an icon, a label, and a value, and includes a `.md-button-group` section with a "Back to Dashboard" navigation button.
- All pages render without any CSS class-not-found visual regressions when viewed in a modern browser.
- No existing authentication or routing logic is altered; only view templates and the stylesheet are modified.
- The application starts successfully with `npm start` and all routes return HTTP 200 for authenticated requests after the changes.

## Technical Approach

### Strategy

All changes are purely front-end: EJS templates and a single CSS file. No backend routes, database schema, or authentication middleware will be touched. The approach is to:

1. Establish the design token foundation in `style.css` (CSS custom properties for color, spacing, radius) for both light and dark theme contexts.
2. Define every missing CSS class so existing template markup becomes functional.
3. Update each EJS view individually, injecting the new branding, icons, and structural markup improvements.

### Color Palette

| Token | Value | Usage |
|-------|-------|-------|
| `--primary` | `#FF6B00` | Buttons, avatar background, active nav items, focus rings |
| `--accent` | `#00BFA5` | Secondary badges, chip borders, hover highlights |

Both tokens must be declared inside the `:root` block (light theme) and overridden inside the `[data-theme="dark"]` block (dark theme) if dark mode is supported.

### Missing CSS Classes

Each class must be defined as follows:

- `.md-profile-item` — flex row with `gap`, `align-items: center`, bottom border separator, padding top/bottom.
- `.md-card-body` — internal padding container inside `.md-card`; provides consistent `padding: 1.5rem`.
- `.md-button-group` — flex row with `gap: 0.75rem` and `flex-wrap: wrap`; used to group CTA buttons.
- `.md-profile-error` — error alert box for profile page; red background tint, `border-left` accent, rounded corners.
- `.md-tech-grid` — CSS Grid container (auto-fill columns, `minmax(120px, 1fr)`, gap) for technology/feature grids on the home page.
- `.md-tech-item` — individual card within `.md-tech-grid`; centered icon + label, hover lift effect.
- `.md-chip` — inline-flex badge; small font size, `border-radius: 999px`, padding, background using `--accent` or status-specific colors.
- `.md-section-cta` — full-width CTA banner section; `background: var(--primary)`, white text, centered content, generous vertical padding.

### View-by-View Changes

**`views/layout.ejs`**
- Navbar brand: `<i class="bi bi-truck"></i> Delivvr`
- `<title>` default: `Delivvr`
- Footer text: replace placeholder with "© 2026 Delivvr. All rights reserved."

**`views/index.ejs`**
- Hero heading: delivery-focused copy (e.g., "Deliver Smarter, Faster, Together")
- Feature icons: swap generic icons for `bi-truck`, `bi-box-seam`, `bi-geo-alt`
- Add `.md-section-cta` block above footer with a sign-up call to action

**`views/login.ejs`**
- Card header: Delivvr wordmark (large bold text or small logo image if asset exists)
- Submit button: `background: var(--primary)`
- Input focus: `border-color: var(--primary); box-shadow: 0 0 0 3px rgba(255,107,0,0.2)`

**`views/signup.ejs`**
- Mirror all login page improvements (branded header, palette, focus states)

**`views/dashboard.ejs`**
- Welcome banner: `<h2>Welcome back, <%= user.name %>!</h2>` inside a styled `.md-card` with a `bi-truck` icon
- Stats: wrap each stat in `.md-card > .md-card-body`
- Status values displayed as `<span class="md-chip">...</span>`

**`views/profile.ejs`**
- Avatar: `<div class="md-avatar">JS</div>` (initials extracted from user name via EJS), styled as a circle with `background: var(--primary)`, white text, `width/height: 80px`, `border-radius: 50%`, `font-size: 2rem`, centered flex
- Profile fields: each wrapped in `<div class="md-profile-item"><i class="bi bi-..."></i><span class="label">Field</span><span class="value"><%= user.field %></span></div>`
- Button group: `<div class="md-button-group"><a href="/dashboard" class="md-button">Back to Dashboard</a></div>`
